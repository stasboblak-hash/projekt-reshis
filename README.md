# Решись Авиа — прогноз спроса

Полнофункциональное решение раздела «Разработка» кейса «Решись»: веб-интерфейс, backend API, девять сценариев спроса, регистрация/авторизация и сохранение расчётов.

## Возможности

- Выбор маршрута из Москвы, даты вылета и цены билета.
- Расчёт медианного спроса, продаж и свободных мест на backend.
- График девяти квантильных сценариев от 0,1 до 0,9.
- Отдельные линии спроса, фактических продаж и вместимости самолёта.
- Подсветка сценариев, в которых спрос превышает число мест.
- Оценка выручки и маржинальной прибыли.
- Вход и автоматическая регистрация через Kimi OAuth.
- Сохранение расчётов в MySQL и история для каждого пользователя.
- Адаптивный интерфейс и installable PWA.

## Формула

Для каждого сценария `X`:

```text
желают = X_base_demand − price_sensitivity × (цена − base_price)
купят = min(seats, max(0, желают))
```

Основной результат использует сценарий `0.5`. Продажи не могут быть отрицательными или превышать вместимость.

## Стек

React, TypeScript, Vite, Tailwind CSS, Recharts, Hono, tRPC, Drizzle ORM, MySQL, Kimi OAuth, vite-plugin-pwa.

## Данные

- `public/data/forecast.csv` — прогноз, полученный в ML-части проекта: 155 рейсов, пять маршрутов, даты с 1 июня по 1 июля 2026 года.
- `public/data/routes.csv` — названия маршрутов, базовые цены, стоимость перевозки и чувствительность спроса к цене.

Исходные справочные данные кейса: https://gist.github.com/Murkat-git/3ddc868889d3e0d37542d786c8b1aa74

## Запуск

```bash
npm install
npm run db:push
npm run dev
```

Приложение доступно на `http://localhost:3000`. Для работы базы и OAuth нужны переменные из `.env` (образец — `.env.example`). При самостоятельном развёртывании экспортированного кода необходимо подключить собственные MySQL и OAuth: платформенные база и Kimi Login не переносятся автоматически.

Production:

```bash
npm run build
npm start
```

Проверки:

```bash
npm run check
npm run test
```

## Структура

- `api/forecast-service.ts` — чтение CSV и расчётный движок.
- `api/forecast-router.ts` — публичные прогнозы и защищённые сохранение/история.
- `contracts/forecast.ts` — общие типы и чистые функции расчёта.
- `src/pages/Home.tsx` — основной рабочий интерфейс.
- `src/components/forecast/DemandChart.tsx` — график распределения спроса.
- `db/schema.ts` — пользователи и сохранённые расчёты.

## Версия для виртуального хостинга Timeweb

В каталоге `timeweb/` находится отдельная PHP/MySQL-версия с тем же интерфейсом и расчётами. Она использует регистрацию по email и паролю, автоматически создаёт таблицы и не требует Node.js или OAuth-секретов на хостинге. Подробная установка: `timeweb/README.md`.

## Использование ИИ

При разработке использован Kimi (Moonshot AI) как ИИ-ассистент для анализа ТЗ, проектирования интерфейса и помощи с кодом. Расчёты в готовом приложении детерминированы и выполняются backend-кодом без обращения к генеративной модели.
