# Решись Авиа — версия для виртуального хостинга Timeweb

Это самостоятельная PHP/MySQL-версия приложения. Она сохраняет интерфейс, девять сценариев спроса, график, ограничение по местам, регистрацию, авторизацию и личную историю расчётов. Вместо Kimi OAuth используется вход по email и паролю, поэтому внешние OAuth-секреты не нужны.

## Быстрая установка в Timeweb

1. В разделе **«Сайты» → «Мои сайты»** создайте сайт, например `reshis`.
2. В **«Домены и SSL» → «Добавить домен»** создайте бесплатный технический домен в зоне `tw1.su`, `tw1.ru` или `webtm.ru` и привяжите его к сайту.
3. В **«Базы данных»** создайте базу MySQL и задайте пароль. Полное имя базы будет с префиксом аккаунта; имя пользователя совпадает с именем базы.
4. Откройте **«Файловый менеджер» → `reshis/public_html`**. Удалите только стандартную заглушку `index.htm`.
5. Загрузите готовый ZIP через **«Загрузить и разархивировать»**. После распаковки `index.html`, `config.php`, `.htaccess`, папки `api`, `assets` и `data` должны находиться непосредственно в `public_html`, без лишней вложенной папки.
6. Откройте `public_html/config.php` в редакторе и замените три placeholder-значения:
   - `ВСТАВЬТЕ_ИМЯ_БАЗЫ` в поле `name`;
   - `ВСТАВЬТЕ_ИМЯ_БАЗЫ` в поле `user`;
   - `ВСТАВЬТЕ_ПАРОЛЬ_БАЗЫ` в поле `password`.
   Поля `host = localhost` и `port = 3306` обычно менять не нужно.
7. В настройках сайта выберите **PHP 8.2 или новее**. Откройте технический домен. Таблицы `users` и `saved_calculations` создадутся автоматически при первой регистрации; импортировать SQL не нужно.
8. Проверьте расчёт, затем регистрацию и сохранение. После привязки своего домена выпустите SSL в **«Домены и SSL» → «SSL-сертификаты»**.

Не публикуйте заполненный `config.php` и не отправляйте пароль базы в чат. Бесплатный пробный период виртуального хостинга составляет 10 дней; дальше тариф нужно оплатить.

Официальные инструкции Timeweb:
- создание БД: https://timeweb.com/ru/docs/virtualnyj-hosting/bazy-dannyh/sozdanie-bazy-dannyh/
- подключение к БД: https://timeweb.com/ru/docs/virtualnyj-hosting/bazy-dannyh/podklyuchenie-k-baze-dannyh/
- загрузка в `public_html`: https://timeweb.com/ru/docs/virtualnyj-hosting/cms/ustanovka-cms/
- технический домен: https://timeweb.com/ru/docs/virtualnyj-hosting/perenos-sajtov-na-hosting/perenos-pri-pomoshchi-terminala/

## Что работает

- Пять маршрутов из Москвы и 155 рейсов на даты 01.06–01.07.2026.
- Медианный спрос и восемь дополнительных квантильных сценариев.
- `желают = X_base_demand − price_sensitivity × (цена − base_price)`.
- `купят = min(seats, max(0, желают))`.
- График спроса/продаж, линия вместимости, выручка и маржинальная прибыль.
- Регистрация по email, безопасные PHP-сессии, CSRF-проверки и `password_hash`.
- Сохранение пересчитывается на сервере; история строго фильтруется по пользователю.
- Адаптивный интерфейс и PWA.

## API

- `GET /api/meta`
- `POST /api/calculate`
- `GET /api/me`
- `POST /api/register`
- `POST /api/login`
- `POST /api/logout`
- `POST /api/save`
- `GET /api/history`

Все POST-запросы принимают JSON и требуют заголовок `X-CSRF-Token`, полученный из `/api/me`. Frontend делает это автоматически.

## Сборка из исходников

Для загрузки на хостинг сборка и Node.js не нужны — используйте готовый ZIP. Для изменения исходников:

```bash
npm install
npm run check
npm run test
npm run lint
npm run package
```

Результат появится в `deploy/public_html`. Содержимое этой папки и нужно архивировать/загружать. PHP API находится в `backend`, фронтенд — в `src`; общие CSV автоматически копируются из корневого `public/data` репозитория.

## Использование ИИ

При разработке использован Kimi (Moonshot AI) как ИИ-ассистент для анализа ТЗ, проектирования интерфейса и помощи с кодом. Готовые расчёты выполняются детерминированным PHP-кодом без обращения к генеративной модели.
